About StudentSync

StudentSync Version 1 is a Python command-line application that allows users to manage student records directly from the terminal. The project supports adding, viewing, editing, searching, and deleting students while storing all information permanently using JSON.

Features

➕

Add Students

Create student records.

📋

View Students

Display all stored records.

🔍

Search

Find students instantly.

✏️

Edit

Update student information.

🗑️

Delete

Remove records permanently.

🏆

Auto Grades

Average & grades calculated automatically.
